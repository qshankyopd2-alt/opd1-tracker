## 2026-09-06 - Prevent Information Leakage in JSON API Responses
**Vulnerability:** The application was catching generic `Exception` objects and casting them directly to strings (`str(e)`) within JSON API responses sent to the client.
**Learning:** This is a common pattern for "helpful" debugging messages, but it leaks internal server state, stack trace hints, and potentially sensitive operational data to unauthenticated or unauthorized frontend clients. Additionally, Bandit flags local requests using `verify=False` as high-severity issues, which needed explicit #nosec B501 suppression since the local Riot client inherently uses a self-signed certificate.
**Prevention:** Always return generic, non-specific error messages to clients (e.g., "Failed to save settings") and log the raw exception (including stack trace) server-side via `app.logger.exception()` or the module's equivalent logger. Use `# nosec B501` to suppress known-safe local-only self-signed TLS validations.
